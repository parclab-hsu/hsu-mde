# 추정값·힘 점검

종이컵·플라스틱 컵·물병 실험에 쓴 **추정값**(옆벽 강성·벽 두께·질량·마찰)과 **계산된 힘·관절 토크**를 공개 문헌, 독립 계산,
결과 데이터로 점검했습니다. 기준: 2026-10-25. **이 페이지의 지적 사항은 아직 결과에 반영하지 않았습니다.**
다른 페이지의 수치는 아래 한계를 안고 있습니다.

## 추정값과 공개 문헌

| 항목 | 이 사이트의 값 | 공개 문헌 | 판정 |
|---|---|---|---|
| 종이컵 16 oz 옆벽 강성 (지름 6.35 mm 줄이는 힘) | 4.4 N | 시판 컵 시험값 3.5–5.3 N (US 11,767,639 B2) | 범위 안 |
| PET 컵 옆벽 강성 (9 / 16 / 20 / 24 oz) | 0.70 / 0.72 / 0.82 / 0.84 N | PET 컵 실측값은 찾지 못함. 열성형 플라스틱 컵 3–11 N (US 8,152,018 B2, US 10,477,998 B2, US 10,059,037 B2) | **3–6배 낮을 수 있음** |
| PET 컵 16 oz 질량 | 12 g | 약 15 g (출하중량 환산, 포장 포함) | 범위 안 |
| PET 물병 500 ml 질량 | 14 g | 8–11 g (경량 생수병) | **높음** |
| PET 물병 벽 두께 | 0.25 mm | 질량 8–12 g이면 평균 0.12–0.18 mm | **두꺼움** |
| PET 물병 옆벽 강성 | 9.8 N | 실측값을 찾지 못함 | 판정 불가 (벽 두께 0.15 mm면 3.2 N, 0.20 mm면 6.0 N) |
| 손가락–컵 마찰계수 | 0.5 | 피부–재료 0.46±0.15, 손끝–매끈한 고분자 필름 1.1–1.2 | 범위 안 (보수적) |
| Allegro Hand 관절 토크 한계 | 0.7 N·m | 제조사 사양 0.7 N·m, Isaac Lab 손 모델 설정 0.5 N·m | 맞음 |

- 옆벽 강성은 사이트의 모델로 다시 계산했을 때 독립 계산과 3 % 안에서 맞았습니다. 차이는 계산이 아니라 **입력 추정값**에서 옵니다.
  PET 컵은 테두리 강성 추정이 낮은 쪽으로 치우쳐 있어, 문헌 범위로 올리면 옆벽 강성이 3–5 N이 됩니다.
- 물병은 벽 두께와 질량이 서로 맞지 않습니다. 실제 생수병에는 가로 줄무늬(리브)가 있어 더 단단한 쪽으로 작용합니다.

## 계산된 힘·토크

| 항목 | 점검 결과 |
|---|---|
| 관절 토크가 설정값을 넘는다 | 손가락이 설정 토크에서 멈추도록 닫지만, 꽉 쥐는 구간에서 기록된 관절 토크가 설정의 1.3–3.7배인 스텝이 있습니다. 순간 최대(0.84–1.11 N·m)는 대부분 이 초과분입니다 |
| 엄지 회전 관절 | 엄지 회전 관절은 토크로 제어하지 않고 고정되어 있어 반력을 그대로 받습니다(0.5–0.9 N·m). 실제 손이라면 밀려날 수 있습니다 |
| 0.7 N·m 넘는 스텝 | 종이컵 27, 물병(빈 병) 8, 물병(1/3) 13, 물병(가득·마개 엶) 18스텝. PET 컵은 전 구간 0.26 N·m 이하 |
| 손가락별 힘 | 꽉 쥐기에서 손가락 하나가 14–27 N(종이컵), 18–22 N(물병). Allegro Hand 손끝이 낼 수 있는 힘(약 7–15 N, 추정)을 넘습니다 |
| 들고 있는 동안의 힘 평형 | 공중에 든 상태의 일부 스텝(접촉 스텝의 약 40 %)에서 컵의 수평 힘 평형이 완전히 맞지 않은 채 기록되었습니다. 9 oz 컵을 내려놓을 때 접촉력이 7.0 N과 10.8 N을 오가는 것도 이 때문입니다 |
| 마찰 여유 | 원뿔형 컵은 손가락 힘의 일부가 컵을 위로 밀어 올리는데, 이를 빼지 않아 빈 컵의 마찰 여유가 크게 나옵니다(예: 9 oz 「33배」). 물이 든 컵의 값은 영향이 작습니다 |
| 변형 크기 | 최대 벽 변위가 PET 9 oz 9.9 mm, 16 oz 8.7 mm, 종이컵 9.3 mm로 모델이 정확한 범위(약 3 mm)를 넘습니다. 물병(2.4 mm)은 범위 안입니다 |

## 다음 단계

1. PET 컵 옆벽 강성을 실물로 잽니다(평판 두 장으로 높이 2/3 지점을 눌러 힘–지름 곡선). 그 전까지 PET 컵 강성은 문헌 범위(3–11 N)
   쪽으로 다시 잡은 경우와 함께 비교합니다.
2. 물병의 벽 두께·질량을 경량 생수병 값(0.16 mm, 9–12 g)으로 맞춥니다.
3. 힘 평형과 관절 토크 계산을 고쳐, 설정 토크에서 정착한 값과 순간 최대를 나누어 기록합니다. 엄지 회전 관절도 토크 한계를 둡니다.
4. 관절 한계를 0.7 N·m와 0.5 N·m 두 기준으로 비교합니다.

## 강화학습(PPO) 환경 점검

같은 컵·물병을 Isaac Lab 강화학습(PPO) 환경으로도 만들었습니다(내부 저장소). 점검 결과 **아직 학습 결과를 낼 단계가 아닙니다.**

| 항목 | 상태 |
|---|---|
| 환경 | 종이컵·PET 컵 4종·물 1/3·2/3·물병 다섯 경우를 등록하고 기동을 확인 |
| 관절 토크 한계 | 시뮬레이션에서 0.7 N·m로 제한됨(학습한 손은 대부분의 스텝에서 한계에 붙어 있음) |
| 「찌그러뜨림」 판정 | 판정 기준이 모델의 정확한 범위(약 3 mm)여서, 사람이 평범하게 쥐어도 넘습니다. 기준을 다시 정해야 함 |
| 들어 올리기 보상 | 컵만 따로 들어 올리는 편법(손 안에서 50–80 mm 미끄러짐)이 학습되어 손과 함께 드는 보상으로 바꿈. 짧은 학습(500회)으로는 아직 들기를 못 배움 |
| 물성 무작위화 | 마찰·질량·벽 강성을 범위 안에서 바꾸는 기능을 넣음(켜고 학습한 결과는 아직 없음) |
| 재현성 | 학습 1회(seed 1개)뿐. 결과 보고는 seed 3개 이상으로 할 예정 |

위 항목이 고쳐지기 전의 수치는 **모델 동작을 보여 주는 예시**입니다.
