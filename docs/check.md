# 추정값·힘 점검

종이컵·플라스틱 컵·물병 실험에 쓴 **추정값**(옆벽 강성·벽 두께·질량·마찰)과 **계산된 힘·관절 토크**를 공개 문헌, 독립 계산,
결과 데이터로 점검했습니다(2026-10-25). **같은 날 지적 사항을 반영해 13개 실험을 모두 다시 계산했고**, 다른 페이지의 수치와 영상은
반영한 뒤의 값입니다. 아래 표의 「이전」은 2026-10-24 판입니다.

## 다음 단계

1. PET 컵·물병 옆벽 강성을 실물로 잽니다(평판 두 장으로 눌러 힘–지름 곡선).
2. 손가락 관절이 컵을 통해 서로 영향을 주는 꽉 쥐기 구간에서 토크 조절을 더 다듬습니다.
3. 손끝 힘이 Allegro Hand 능력 안에 들도록 꽉 쥐기 설정과 쥐는 자세를 다시 봅니다.

## 강화학습(PPO) 환경 점검

같은 컵·물병을 Isaac Lab 강화학습(PPO) 환경으로도 만들었습니다(내부 저장소). 점검 결과 **아직 학습 결과를 낼 단계가 아닙니다.**

| 항목 | 상태 |
|---|---|
| 환경 | 종이컵·PET 컵 4종·물 1/3·2/3·물병 다섯 경우를 등록하고 기동을 확인 |
| 물성 | 위 수정(PET 컵·물병)이 강화학습 환경에도 그대로 들어감. 이전 강성으로 학습한 PET 컵 결과는 다시 학습하기 전까지 쓰지 않음 |
| 관절 토크 한계 | 시뮬레이션에서 0.7 N·m로 제한됨(학습한 손은 대부분의 스텝에서 한계에 붙어 있음) |
| 「찌그러뜨림」 판정 | 판정 기준이 모델의 정확한 범위(약 3 mm)여서, 사람이 평범하게 쥐어도 넘습니다. 기준을 다시 정해야 함 |
| 들어 올리기 보상 | 컵만 따로 들어 올리는 편법(손 안에서 50–80 mm 미끄러짐)이 학습되어 손과 함께 드는 보상으로 바꿈. 짧은 학습(500회)으로는 아직 들기를 못 배움 |
| 물성 무작위화 | 마찰·질량·벽 강성을 범위 안에서 바꾸는 기능을 넣음(켜고 학습한 결과는 아직 없음) |
| 재현성 | 학습 1회(seed 1개)뿐. 결과 보고는 seed 3개 이상으로 할 예정 |

위 항목이 고쳐지기 전의 수치는 **모델 동작을 보여 주는 예시**입니다.
