# 종이컵 쥐기

Allegro Hand가 탁자 위 16 oz 종이컵(윗지름 90 mm, 아랫지름 60 mm, 높이 136 mm)을 옆에서 감싸 쥐고, 80 mm 들어 올린 뒤
더 세게 쥐었다가 풀고, 내려놓는 동작입니다. 각 손가락 관절은 정해진 토크까지만 힘을 내는 **토크 제한 쥐기**로 닫습니다.
컵 벽의 색은 변형 방향(적색: 바깥으로, 청색: 안쪽으로)입니다. 기준: 2026-10-25, Isaac Sim 5.0.0.
[추정값·힘 점검](check.md)에 따라 힘 계산(컵의 힘 평형, 관절 토크 조절, 엄지 회전 관절)을 고쳐 다시 계산했습니다. 종이컵 물성은 그대로입니다.

## 동작 순서

| 단계 | 내용 |
|---|---|
| 접근 | 손을 편 채 옆에서 다가간다 |
| 예비 자세 | 손가락마다 컵에 닿기 직전까지 미리 굽힌다 |
| 쥐기 | 관절 토크 0.10 N·m까지 닫는다. 탁자 위의 가벼운 컵은 엄지에 끌려 손바닥 쪽으로 약 20 mm 미끄러진다 |
| 들기 | 손가락 마찰로 무게를 버틸 수 있으면 80 mm 들어 올린다 |
| 꽉 쥐기 → 되돌리기 | 0.35 N·m까지 올렸다가 0.10 N·m로 되돌린다 |
| 내려놓기 → 펴기 → 물러나기 | 컵을 내려놓고 손을 편다 |

## 결과

| 시점 | 관절 토크 설정 | 접촉력 합 | 검지 / 중지 / 약지 / 엄지 / 손바닥 | 테두리 변형(안쪽 / 바깥) |
|---|---|---|---|---|
| 쥐었을 때 | 0.10 N·m | 16.8 N | 3.1 / 2.1 / 1.8 / 4.2 / 5.5 N | 4.2 / 3.9 mm |
| 들었을 때 | 0.10 N·m | 16.9 N | 3.3 / 2.1 / 1.5 / 4.4 / 5.6 N | 4.3 / 3.9 mm |
| 꽉 쥐었을 때 | 0.35 N·m | 70.0 N | 8.7 / 14.9 / 7.6 / 19.2 / 19.6 N | 8.4 / 8.0 mm |
| 되돌렸을 때 | 0.10 N·m | 17.0 N | 1.6 / 2.2 / 3.1 / 3.4 / 6.7 N | 4.9 / 4.4 mm |
| 놓은 뒤 | — | 0 N | — | 0 mm (탄성 복원) |

- 원뿔형 컵은 손가락이 미는 힘의 일부(약 11 %)가 컵을 위로 밀어 올리므로, 컵 무게(약 14 g, 0.14 N)보다 손가락이 미는 힘 쪽이 큽니다.
  마찰이 받쳐야 하는 힘에 비해 마찰로 버틸 수 있는 힘은 들고 있는 동안 최소 4.6배입니다(2026-10-24 판은 밀어 올리는 힘을 빼지 않아 55배).
- 컵 옆벽의 단단함은 시판 16 oz 종이컵의 옆벽 강성 시험값(지름 6.35 mm를 줄이는 데 3.5–5.3 N)에 맞췄습니다.
- 접촉력과 관절 토크의 시간 이력은 [관절 토크](torque.md)에 있습니다.
- 같은 동작으로 투명 PET 컵을 쥔 결과는 [플라스틱 컵 쥐기](plastic-cup.md)에 있습니다.
- 2026-10-24 판은 손이 컵 벽을 파고든 것처럼 보이던 문제(최대 약 1.6 mm)를 고쳐 다시 찍었습니다. 화면의 손과 컵 벽 겹침은
  전 구간 최대 0.34 mm로, 종이 두께 0.46 mm보다 작습니다.

!!! warning "한계"
    - 컵 벽은 **탄성만** 표현합니다. 실제 종이컵은 이 정도 힘이면 주름이 잡히거나 찌그러집니다. 꽉 쥐기(70 N, 벽 변위 약 8.4 mm)는 모델이 정확한 범위(약 3 mm)를 크게 넘는 외삽입니다.
    - 꽉 쥐기에서 손가락 하나의 힘(최대 20 N)은 Allegro Hand 손끝 능력(약 7–15 N, 추정)을 넘습니다. 관절 토크는 꽉 쥐는 구간에서
      순간적으로 설정의 1.5–3배까지 기록되는 스텝이 있습니다(최대 0.80 N·m, 0.7 N·m 넘은 스텝 3개).
    - 컵은 미끄러지기만 하고 기울지는 않습니다. 컵이 들려 있는 동안에는 손가락 마찰이 받치는 힘을 관절 토크에 넣었습니다.
    - 물성(종이 탄성계수·두께·질량·마찰)은 잠정값입니다.
